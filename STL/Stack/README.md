# Stack 

- Stack follows LIFO.
- LIFO : Last In First Out.


- There are mainly three operation we do in stack which are..

1. push() : To add an element we use push() operation.
(emplace() : This works just as push() which will insert the element into the stack.)
2. pop() : To delete the last element we use pop() which will delete the top element.
3. top() : To know which is the last element we have insert into the stack we use top().


- Beside this there are other operations too like..

1. size() : To know the size of the stack.
2. empty() : To know wether the stack is empty or not.
3. swap() : To swap values between the two stack.
