# vector : 

- So basically vactor is like an array, but unlike in an array we can not change the size of it but in the vector we can change the size of it.

- So vactor is more flexible, more reliable, and easy to use.

## Declaration of the vector : 

Syntax : 

`vector <int> v;` 

- vector : It's a key word that indicate we are using a vector for the data.
- int : It's telling that we are gonna use integer value for the data. Here the data type can be anything.
- v : It's a name of the vector which we will use for the call it or to do more work.

- Other things like declaring the vector, adding the elements, display the elements of the vector with the help of the for loop etc.. is in the "vector.cpp" file.
